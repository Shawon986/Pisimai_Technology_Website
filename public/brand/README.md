# PISIMAI TECHNOLOGY — Logo assets

Initial vector asset set for the selected “Intelligence Orbit” brand direction.

- `pisimai-horizontal-dark.svg` — primary horizontal lockup for dark backgrounds
- `pisimai-horizontal-light.svg` — horizontal lockup for light backgrounds
- `pisimai-stacked-dark.svg` — stacked lockup
- `pisimai-symbol.svg` — standalone P/orbit emblem
- `pisimai-monochrome.svg` — single-colour version for dark backgrounds
- `pisimai-favicon.svg` — browser/app icon

Brand colours:
- Obsidian Navy: #070B16
- Deep Technology Blue: #101B32
- Electric Cyan: #20D9F2
- Digital Blue: #168BFF
- Neural Violet: #8B45F5
- Ice White: #EAF2FF

Tagline: Engineering Tomorrow. Empowering Today.

These are scalable SVG concept assets. The horizontal logo is intended for the website header and footer. Review at actual display sizes before treating this concept artwork as a final trademark master.
